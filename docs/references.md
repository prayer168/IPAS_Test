# 來源與題目整理說明

查核日期：2026-10-25（Asia/Taipei）

## 官方試題來源

- 經濟部產業發展署 iPAS AI 應用規劃師學習資源：<https://ipd.nat.gov.tw/ipas/certification/AIAP/learning-resources>
- `題庫來源/` 中 14 份 PDF 皆由上述頁面公告連結下載，網站索引依等級、民國年度、梯次與科目整理。
- 官方 114 年度能力鑑定簡章資料顯示，初級每科 75 分鐘、中級每科 90 分鐘。資料來源：<https://ipd.nat.gov.tw/ipas/DownloadFile.ashx?filename=25137541-067d-451e-b875-08baf8951eae_114%E5%B9%B4%E5%BA%A6AI%E6%87%89%E7%94%A8%E8%A6%8F%E5%8A%83%E5%B8%AB%E8%83%BD%E5%8A%9B%E9%91%91%E5%AE%9A%E7%B0%A1%E7%AB%A0%28%E5%88%9D%E3%80%81%E4%B8%AD%E7%B4%9A%29_1140519.pdf&type=10>。計時模式沿用此科目級時長。

## 互動題目

- `data/questions.js` 前 27 題是從 115 年公告 PDF 人工整理的選擇題，保留題目核心文字、答案順序與答案字母；解析及干擾選項說明是另行撰寫的學習輔助內容。
- 115 年試卷目前只有部分題目完成互動整理；官方 PDF 仍保留完整題目。未完成校對的試卷在考場清單標示為「試作模式」，不得視為完整正式考卷。
- 114 年試卷採不同欄位排版，尚未加入互動題庫，避免答案欄位配對錯誤。
- `window.IPAS_MOCK_QUESTIONS` 是新編情境題，並非官方題；每題有獨立模擬題標記及解題說明。
