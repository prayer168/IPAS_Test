# iPAS AI 應用規劃師備考資料室

繁體中文靜態網站原型，收錄官方歷屆試題 PDF，並提供已校對題目的主題練習、隨機測驗、限時作答和模擬題解析。

## 本機預覽

直接開啟 `index.html`，或在專案資料夾執行：

```powershell
python -m http.server 8000
```

瀏覽 `http://localhost:8000`。

## 題庫狀態

- 14 份官方 PDF 完整收錄在 `題庫來源/`。
- 27 題歷屆互動題目前已整理答案與解析；清單中的考卷仍有 50 題，題庫尚未完整時會顯示「試作模式」。
- 8 題新編模擬題與官方題分開儲存、篩選和標示。
- 逐題解析是學習輔助說明，不是官方解答說明。

## 檔案

- `index.html`：頁面與導覽結構
- `styles.css`：響應式版面與元件樣式
- `app.js`：篩選、作答、抽題、計時與計分互動
- `data/metadata.js`：14 份官方試卷中繼資料
- `data/questions.js`：歷屆題和新編模擬題資料
- `題庫來源/`：官方 PDF 原卷
- `dist/`：部署用靜態網站檔案
